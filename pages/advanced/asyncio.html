Async IO

Write concurrent code using the async/await syntax.

What is Asyncio?

asyncio is a library to write concurrent code using the async/await syntax. It is a perfect fit for IO-bound and high-level structured network code (like building high-performance web servers or making multiple API requests).

Coroutines with async and await

A coroutine is a specialized version of a Python generator function. You define it using async def and pause its execution using await.

import asyncio

async def fetch_data():
    print("Fetching data...")
    await asyncio.sleep(2)  # Non-blocking delay
    return "Data loaded"

async def main():
    print("Start")
    result = await fetch_data()
    print(result)
    print("End")

# You must use asyncio.run() to execute the top-level coroutine
asyncio.run(main())

Running Tasks Concurrently

You can run multiple coroutines at the exact same time using asyncio.gather().

import asyncio

async def download_file(name, delay):
    print(f"Starting {name}...")
    await asyncio.sleep(delay)
    return f"{name} finished"

async def main():
    # These will run concurrently, taking only 3 seconds total!
    results = await asyncio.gather(
        download_file("File 1", 2),
        download_file("File 2", 3),
        download_file("File 3", 1)
    )
    print(results)

asyncio.run(main())
