Multiprocessing in Python

Bypass the Global Interpreter Lock (GIL) for true parallel computing.

What is Multiprocessing?

Unlike multithreading, multiprocessing creates separate memory spaces and completely independent Python processes. This is the recommended approach for CPU-heavy tasks, as it fully utilizes multiple processor cores.

Creating a Process

You can use the Process class from the multiprocessing module to spin up a new process.

import multiprocessing
import time

def cpu_heavy_task(name):
    print(f"Task {name} starting...")
    # Simulate heavy computation
    result = [i * i for i in range(10000000)]
    print(f"Task {name} finished!")

if __name__ == '__main__':
    p1 = multiprocessing.Process(target=cpu_heavy_task, args=("A",))
    p2 = multiprocessing.Process(target=cpu_heavy_task, args=("B",))

    p1.start()
    p2.start()

    p1.join()
    p2.join()
    print("All processes complete.")

Using a Process Pool

If you have many tasks, the Pool object makes it easy to divide the workload across multiple CPU cores automatically.

import multiprocessing

def square(n):
    return n * n

if __name__ == '__main__':
    numbers = [1, 2, 3, 4, 5]
    
    # Creates a pool of workers matching your CPU core count
    with multiprocessing.Pool() as pool:
        results = pool.map(square, numbers)
        
    print(results)
