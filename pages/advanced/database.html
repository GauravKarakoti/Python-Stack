Database Interaction

Learn how to connect Python to a database using SQLite.

SQLite in Python

Python comes with a built-in module called sqlite3, which allows you to create and interact with SQL databases without needing to install external database servers.

Concept: You need a Connection object to connect to the database and a Cursor object to execute SQL commands.

Creating a Table & Inserting Data

import sqlite3

# Connect to a file-based database (it creates one if it doesn't exist)
conn = sqlite3.connect("users.db")
cursor = conn.cursor()

# Execute a SQL Query to create a table
cursor.execute("CREATE TABLE IF NOT EXISTS students (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)")

# Insert data
cursor.execute("INSERT INTO students (name, age) VALUES ('Alex', 22)")

# Save (commit) the changes and close the connection
conn.commit()
conn.close()

Fetching Data

Use the fetchall() method to retrieve data from the database.

import sqlite3

conn = sqlite3.connect("users.db")
cursor = conn.cursor()

# Select all students
cursor.execute("SELECT * FROM students")
rows = cursor.fetchall()

for row in rows:
    print(row)

conn.close()
