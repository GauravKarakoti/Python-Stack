Multithreading in Python

Learn how to run multiple tasks concurrently to speed up your programs.

What is Multithreading?

A thread is the smallest unit of execution within an operating system. Multithreading allows a single program to run multiple threads simultaneously, which is highly useful for tasks that involve waiting (like downloading files or reading from a database).

Important: Due to Python's Global Interpreter Lock (GIL), multithreading is best for I/O-bound tasks, not CPU-bound tasks.

Creating a Thread

Python provides the built-in threading module to create and manage threads easily.

import threading
import time

def print_numbers():
    for i in range(5):
        time.sleep(1)
        print("Number:", i)

# Create a thread
t1 = threading.Thread(target=print_numbers)

# Start the thread
t1.start()

print("This prints immediately while the thread is running in the background!")

Joining Threads

If you want the main program to wait until a thread finishes its execution, you use the .join() method.

import threading
import time

def worker():
    print("Worker started")
    time.sleep(2)
    print("Worker finished")

t = threading.Thread(target=worker)
t.start()

# Wait for the thread to complete before moving on
t.join()
print("Main program finished.")
