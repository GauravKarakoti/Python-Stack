Django Web Framework

The web framework for perfectionists with deadlines.

What is Django?

Django is a high-level Python web framework that encourages rapid development and clean, pragmatic design. Unlike Flask, which is a microframework, Django comes with "batteries included" (built-in ORM, admin panel, authentication, etc.).

The MTV Architecture

Django follows the Model-Template-View architectural pattern.

  • Model: Handles the database structure and queries.
  • Template: The frontend HTML, controlled by Django's template language.
  • View: The logic that fetches models and renders templates.

Starting a Project

Run these commands in your terminal to create and start a Django project.

# 1. Install Django
pip install django

# 2. Create a new project
django-admin startproject myproject

# 3. Move into the directory
cd myproject

# 4. Run the development server
python manage.py runserver

Creating an App

A Django project is made up of multiple apps. Create an app using this command:

# Create a new app called 'blog'
python manage.py startapp blog

Defining a Model

Models define your database schema. Here is an example of an Article model in models.py:

from django.db import models

class Article(models.Model):
    title = models.CharField(max_length=100)
    content = models.TextField()

    def __str__(self):
        return self.title

Creating a View

Views handle the logic and return HTTP responses. Here is a simple function-based view in views.py:

from django.http import HttpResponse

def home_view(request):
    return HttpResponse("Hello, Django!")

Configuring URLs

Map your views to URLs in urls.py so users can access them in their browser.

from django.urls import path
from . import views

urlpatterns = [
    path('', views.home_view, name='home'),
]
