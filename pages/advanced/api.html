Working with APIs

Learn how to make HTTP requests and fetch live data from the web.

What is an API?

API stands for Application Programming Interface. It allows two applications to talk to each other. In Python, we commonly interact with web APIs to fetch JSON data.

Prerequisite: You need to install the requests module using pip install requests.

Making a GET Request

Use the requests.get() function to fetch data from an API endpoint.

import requests

url = "https://api.github.com/users/gauravkarakoti"
response = requests.get(url)

if response.status_code == 200:
    print("Success!")
else:
    print("Failed to retrieve data")

Parsing JSON Data

APIs typically return data in JSON format. The requests library has a built-in .json() decoder.

import requests

response = requests.get("https://api.github.com/users/gauravkarakoti")
data = response.json()

print("Name:", data['name'])
print("Followers:", data['followers'])

Common HTTP Methods

Method Action
GET Retrieve data from a server
POST Send new data to a server (e.g., submitting a form)
PUT Update existing data on the server
DELETE Remove data from the server
