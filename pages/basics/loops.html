Python Loops

Learn how to repeat tasks efficiently using loops in Python.

What are Loops?

Loops are used to execute a block of code repeatedly until a condition is met.

Python mainly provides two types of loops: for loop and while loop.

Example: Printing numbers from 1 to 10 using a loop instead of writing print statements multiple times.

Python for Loop

A for loop is used to iterate through sequences like lists, strings, tuples, or ranges. 

for i in range(1, 6):
    print(i)
Output: 1 2 3 4 5

Python while Loop

A while loop executes as long as the condition is true. 

count = 1

while count <= 5:
    print(count)
    count += 1

Loop Through a String

You can loop through each character of a string. 

word = "Python"

for letter in word:
    print(letter)

Nested Loops

A loop inside another loop is called a nested loop. 

for i in range(1, 4):

    for j in range(1, 4):
        print(i, j)

Loop Control Statements

break

Stops the loop immediately. 

for i in range(5):

    if i == 3:
        break

    print(i)

continue

Skips the current iteration. 

for i in range(5):

    if i == 2:
        continue

    print(i)

pass

Placeholder statement for future code. 

for i in range(5):
    pass

The range() Function

The range() function generates a sequence of numbers.

Example Description
range(5) 0 to 4
range(1, 6) 1 to 5
range(1, 10, 2) Odd numbers from 1 to 9

Using else with Loops

Python allows an else block with loops. 

for i in range(5):
    print(i)

else:
    print("Loop Finished")

Real-Life Example

Loops are commonly used in games, websites, automation scripts, and data processing. 

students = ["Alex", "John", "Emma"]

for student in students:
    print("Welcome", student)

Important Notes

  • Loops reduce repetitive code
  • Indentation is important in Python loops
  • Infinite loops can crash programs
  • Loops improve automation and efficiency
