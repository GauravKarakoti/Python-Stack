Python Operators

Learn how Python operators are used to perform operations on variables and values.

What are Operators?

Operators are special symbols used to perform operations on variables and values.

Python provides different types of operators for mathematical calculations, comparisons, logical operations, and more.

Example: In 5 + 3, the + symbol is an operator.

Arithmetic Operators

Arithmetic operators are used for mathematical calculations.

Operator Name Example
+ Addition 5 + 3
- Subtraction 10 - 2
* Multiplication 4 * 5
/ Division 20 / 4
% Modulus 10 % 3
** Exponentiation 2 ** 3
// Floor Division 10 // 3 
x = 10
y = 3

print(x + y)
print(x - y)
print(x * y)
print(x / y)
print(x % y)

Assignment Operators

Assignment operators are used to assign values to variables. 

x = 5

x += 3
print(x)

x -= 2
print(x)

x *= 4
print(x)

Comparison Operators

Comparison operators compare two values and return either True or False.

Equal To

5 == 5

Not Equal To

5 != 3

Greater Than

10 > 5

Less Than

2 < 8

Greater Than or Equal

5 >= 5

Less Than or Equal

3 <= 9

Logical Operators

Logical operators are used to combine conditional statements.

AND Operator

x = 5

print(x > 2 and x < 10)

OR Operator

x = 5

print(x > 2 or x > 10)

NOT Operator

x = 5

print(not(x > 2))

Identity Operators

Identity operators compare memory locations of two objects. 

x = ["apple", "banana"]
y = x
z = ["apple", "banana"]

print(x is y)
print(x is z)

print(x is not z)

Membership Operators

Membership operators check whether a value exists in a sequence. 

fruits = ["apple", "banana", "mango"]

print("apple" in fruits)
print("grapes" not in fruits)

Bitwise Operators

Bitwise operators work on binary numbers.

Operator Name
& AND
| OR
^ XOR
~ NOT
<< Left Shift
>> Right Shift

Operator Precedence

Operator precedence determines which operation is performed first. 

result = 5 + 2 * 3

print(result)
Multiplication is performed before addition because it has higher precedence.
