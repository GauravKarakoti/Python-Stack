Python Data Types

Understand the different types of data used in Python programming.

What are Data Types?

Data types define the type of value a variable can store in Python.

Python automatically identifies the data type based on the assigned value.

Good to Know: Python is a dynamically typed programming language.

Numeric Data Types

Integer (int)

Stores whole numbers.

age = 21
print(type(age))

Float (float)

Stores decimal values.

price = 99.99
print(type(price))

Complex (complex)

Stores complex numbers.

num = 4 + 5j
print(type(num))

Text Data Type

String (str)

Strings are used to store text values. 

name = "Python"
print(type(name))

Sequence Data Types

List

Ordered and changeable collection. 

fruits = ["Apple", "Mango", "Banana"]

Tuple

Ordered but unchangeable collection. 

colors = ("Red", "Blue", "Green")

Range

Represents a sequence of numbers. 

numbers = range(5)

Mapping Data Type

Dictionary (dict)

Stores data in key-value pairs. 

student = {
    "name": "Alex",
    "age": 20
}

Set Data Types

Set

Unordered collection of unique values. 

numbers = {1, 2, 3, 4}

Frozen Set

Immutable version of a set. 

data = frozenset({1, 2, 3})

Boolean Data Type

Boolean (bool)

Stores either True or False. 

isPythonFun = True
print(type(isPythonFun))

Checking Data Types

Python provides the type() function to check the data type of a variable. 

x = 10
print(type(x))

y = "Hello"
print(type(y))

Type Conversion

You can convert one data type into another using built-in functions. 

age = "20"

convertedAge = int(age)

print(convertedAge)
print(type(convertedAge))
