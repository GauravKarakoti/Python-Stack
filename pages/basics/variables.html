Python Variables

Learn how Python stores and manages data using variables.

What are Variables?

Variables are containers used to store data values in a program.

In Python, you do not need to declare the type of a variable. Python automatically determines the data type based on the value assigned.

Example: A variable can store numbers, text, lists, and many other types of data.

Creating Variables in Python

Variables are created when you assign a value using the = operator. 

name = "Gaurav"
age = 20
height = 5.9

print(name)
print(age)
print(height)

Rules for Naming Variables

  • Variable names must start with a letter or underscore (_)
  • They cannot start with a number
  • Variable names are case-sensitive
  • Spaces are not allowed
  • Use meaningful variable names

Valid Variables

username = "Alex"
_age = 21
user1 = "John"

Invalid Variables

1name = "Alex"
user-name = "John"
first name = "Sam"

Multiple Variable Assignment

Python allows assigning multiple values in a single line. 

x, y, z = 10, 20, 30

print(x)
print(y)
print(z)

Changing Variable Values

Variables can be updated anytime during program execution. 

score = 50
print(score)

score = 100
print(score)

Common Data Types in Variables

Integer

Stores whole numbers.

age = 20

Float

Stores decimal numbers.

price = 99.99

String

Stores text values.

name = "Python"

Boolean

Stores True or False.

isActive = True

Best Practices

  • Use descriptive variable names
  • Avoid single-letter variable names
  • Use snake_case naming style
  • Keep variable names short but meaningful
