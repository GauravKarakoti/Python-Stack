Python Conditional Statements

Learn how Python makes decisions using conditional statements.

What are Conditional Statements?

Conditional statements are used to perform different actions based on different conditions.

Python uses keywords like if, elif, and else to control the flow of a program.

Example: If a student scores more than 40 marks, they pass the exam.

The if Statement

The if statement executes a block of code only if the condition is true.

The else Statement

The else statement executes when the condition inside the if statement is false.

The elif Statement

The elif statement allows checking multiple conditions.

Nested Conditional Statements

You can place one conditional statement inside another.

Short Hand if Statement

Python allows writing simple if statements in one line.

Using Logical Operators

Logical operators help combine multiple conditions.

AND Operator

age = 25
citizen = True

if age >= 18 and citizen:
    print("Eligible")

OR Operator

isWeekend = True
isHoliday = False

if isWeekend or isHoliday:
    print("Relax")

NOT Operator

loggedIn = False

if not loggedIn:
    print("Please Login")

Comparison Operators in Conditions

Operator Meaning Example
== Equal To x == y
!= Not Equal To x != y
> Greater Than x > y
< Less Than x < y
>= Greater Than or Equal To x >= y
<= Less Than or Equal To x <= y

Important Notes

  • Python uses indentation to define blocks of code
  • Conditions return either True or False
  • Indentation is mandatory in Python
  • You can combine multiple conditions using logical operators
