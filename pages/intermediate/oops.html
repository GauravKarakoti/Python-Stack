Object-Oriented Programming (OOP)

Learn how to structure your code using Classes and Objects in Python.

What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm that organizes software design around data, or objects, rather than functions and logic.

Key Concept: A Class is a blueprint. An Object is the actual item built from that blueprint.

Creating a Class and Object

You can create a class using the class keyword, and an initialization method called __init__.

Inheritance

Inheritance allows us to define a class that inherits all the methods and properties from another class, promoting code reuse.

Encapsulation

Encapsulation is the bundling of data and methods that operate on that data within a single unit (class). It also involves restricting direct access to some of an object's components using private attributes (prefixed with double underscores __).

Polymorphism

Polymorphism means "many forms." In Python, it allows different classes to have methods with the same name. We can call the same method on different objects without knowing their exact class type.

Abstraction

Abstraction hides complex implementation details and only shows the essential features of an object. In Python, we use the abc (Abstract Base Classes) module to define abstract classes and methods.

(Trinket doesn't support abc module so you can try this code in local)

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius * self.radius

c = Circle(5)
print("Area:", c.area())

Core Principles of OOP Summary

Encapsulation

Hiding private data from the outside world using private attributes (e.g., __name).

Inheritance

Reusing code by inheriting characteristics from a parent class.

Polymorphism

Using a single function or method in different ways for different data types.

Abstraction

Hiding complex implementation details and showing only the essential features.
