Python Modules

Learn how to organize, reuse, and import code using Python modules.

What is a Module?

A module is a file containing Python definitions and statements. Modules allow you to logically organize your Python code, making it easier to understand and use.

Think of it as: A code library or a file containing a set of functions you want to include in your application.

Importing Built-in Modules

Python comes with a large standard library containing many built-in modules. You can use the import keyword to use them.

Using "from ... import"

If you only need a specific function or variable from a module, you can import just that specific part without importing the entire file.

Common Built-in Modules

Python's standard library is extensive. Here are a few commonly used built-in modules:

  • math: Provides mathematical functions like sqrt(), sin(), and constants like pi.
  • random: Contains functions to generate pseudo-random numbers and make random selections.
  • datetime: Supplies classes for manipulating dates and times.
  • os: Allows you to interface with the underlying operating system (e.g., navigating directories).

Working with the CSV Module

The csv module is incredibly useful for reading from and writing to tabular data files (Comma-Separated Values). It handles the formatting and parsing of rows and columns automatically.

(Trinket doesn't support csv module so you can try this code in local)

import csv

# Writing data to a CSV file
with open('students.csv', 'w', newline='') as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Course"])
    writer.writerow(["Alice", "Python Basics"])
    writer.writerow(["Bob", "Data Science"])

# Reading data from a CSV file
with open('students.csv', 'r') as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
