File Handling

Learn how to read, write, and append data to files using Python.

Opening a File

Python has a built-in open() function to open a file. It takes two primary parameters: the file name and the mode.

Modes: "r" (Read), "w" (Write), "a" (Append), "x" (Create)

Reading a File

You can read the entire content of a file using the read() method.

Writing to a File using 'with'

It is good practice to use the with statement when working with files. It automatically closes the file for you.

Important Notes

  • Always close your files to free up memory (or use the with block).
  • Writing ("w") to an existing file will completely overwrite its contents.
  • Use Append ("a") if you want to add content to the end of a file without deleting the old text.
