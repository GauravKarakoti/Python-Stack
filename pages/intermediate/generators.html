Generators

Optimize memory efficiency by generating values on the fly.

What is a Generator?

A generator is a special type of function that returns an iterator object. Instead of returning a single value and destroying its local variables, a generator pauses its execution and saves its state so it can be resumed right where it left off.

Why use them? They are highly memory-efficient. Instead of storing an entire list of numbers in memory, generators compute values one at a time as needed.

The 'yield' Statement

Unlike regular functions that use the return statement, generators use the yield keyword to output data.

Generators with Loops

Generators are typically used inside loops to yield a sequence of values automatically.

Generator Expressions

Similar to list comprehensions, you can create quick generators using parentheses instead of square brackets.
