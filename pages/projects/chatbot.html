Project: AI ChatBot

Build an interactive AI assistant using the Groq API and Llama 3.

Project Overview

In this project, we'll build a fast, terminal-based chatbot utilizing the groq SDK to interface with highly optimized open-source LLMs.

Prerequisites: Run pip install groq and set your GROQ_API_KEY environment variable.

The Code

This script initializes the Groq client and maintains an interactive loop for continuous conversation.

import os
from groq import Groq

# Initialize the client using the environment variable
client = Groq(api_key=os.environ.get("GROQ_API_KEY"))
# Uncomment the next line if you don't wanna set up environment variables and use the API key directly
# client = Groq(api_key="GROQ_API_KEY")    # Replace GROQ_API_KEY with your API key


def chat_with_bot(user_input):
    # Create the completion request
    chat_completion = client.chat.completions.create(
        messages=[
            {
                "role": "user",
                "content": user_input,
            }
        ],
        # Using the Llama 3 8B model via Groq
        model="llama3-8b-8192",
    )
    return chat_completion.choices[0].message.content

# Interactive CLI Loop
print("Bot: Hello! Type 'exit' to quit.")
while True:
    prompt = input("You: ")
    if prompt.lower() == 'exit':
        print("Bot: Goodbye!")
        break
    
    response = chat_with_bot(prompt)
    print("\nBot:", response, "\n")
