Project: Web Scraper

Extract data from websites automatically using Python.

Project Overview

Web scraping is the process of extracting data from websites. We will use the requests library to fetch the HTML, and BeautifulSoup to parse it and find the information we need.

Prerequisites: Run pip install requests beautifulsoup4 in your terminal.

The Code

This script fetches the HTML from a demo website and extracts all the headlines (h2 tags).

import requests
from bs4 import BeautifulSoup

url = "https://news.ycombinator.com/"

# 1. Fetch the webpage
response = requests.get(url)

if response.status_code == 200:
    # 2. Parse the HTML
    soup = BeautifulSoup(response.text, "html.parser")
    
    # 3. Find specific elements (e.g., all span tags with the class 'titleline')
    headlines = soup.find_all("span", class_="titleline")
    
    print("--- Hacker News Top Stories ---")
    for i, headline in enumerate(headlines[:10]):
        print(f"{i+1}. {headline.text}")
else:
    print("Failed to retrieve the webpage.")
